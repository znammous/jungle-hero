# 🌴 بطل الغابة

لعبة لتعلّم جدول الضرب: مغامرة في الغابة، تعمل بدون إنترنت، وكل البيانات محفوظة على الجهاز نفسه.

## التشغيل على اللابتوب
افتح الملف `index.html` بضغطة مزدوجة (يُفضّل متصفح Chrome).

## التشغيل على التابلت (أندرويد)
التثبيت كتطبيق يعمل بدون إنترنت يحتاج أن تُفتح اللعبة **مرة واحدة** من رابط `https`.
بعد ذلك: قائمة Chrome ← «إضافة إلى الشاشة الرئيسية»، وتعمل اللعبة بعدها بدون إنترنت.

## هيكل الملفات
| الملف | الوظيفة |
|---|---|
| `js/data.js` | المناطق والحيوانات والرتب والمعدّات والإعدادات (عدد الأسئلة، مدة السباق...) |
| `js/engine.js` | اختيار الأسئلة حسب نقاط ضعف الطفل وحساب الإتقان |
| `js/store.js` | حفظ ملفات الأطفال على الجهاز |
| `js/app.js` | الشاشات وطريقة اللعب |
| `sw.js` | حفظ ملفات اللعبة للعمل بدون إنترنت |

> عند تعديل أي ملف، غيّر رقم `CACHE` في `sw.js` حتى يصل التحديث للتابلت.
