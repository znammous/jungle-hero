# 🌴 أبطال الغابة

لعبة لتعلّم الرياضيات: مغامرة في عالم من الغابات، كل غابة عملية حسابية (الضرب، القسمة، وقريباً الجمع والطرح والكسور والسالب والموجب). تعمل بدون إنترنت، وكل البيانات محفوظة على الجهاز نفسه.

## التشغيل على اللابتوب
افتح الملف `index.html` بضغطة مزدوجة (يُفضّل متصفح Chrome).

## التشغيل على التابلت (أندرويد)
التثبيت كتطبيق يعمل بدون إنترنت يحتاج أن تُفتح اللعبة **مرة واحدة** من رابط `https`.
بعد ذلك: قائمة Chrome ← «إضافة إلى الشاشة الرئيسية»، وتعمل اللعبة بعدها بدون إنترنت.

## ولي أمر آخر
من لوحة ولي الأمر ← «أضف جهازاً لـ» ← «👑 ولي أمر آخر» يكتب ولي الأمر اسمه فيظهر رمز QR صالح لعشر دقائق ولمرة واحدة. ينضم به جوال الأب أو الأم من «انضم برمز»، فيصبح له ما لولي الأمر: يرى أجهزة العائلة ويضيفها ويفصلها (ولوحة ولي الأمر تبقى برمزها السري). يُسجَّل في `families/{uid}/guardians/{معرّفه}`، و«فصل» جهازه يلغي صلاحياته.

## هيكل الملفات
| الملف | الوظيفة |
|---|---|
| `js/data.js` | الغابات (`WORLDS`) ومناطقها وحيواناتها، والرتب والمعدّات والإعدادات (عدد الأسئلة، مدة السباق...) |
| `js/engine.js` | بناء أسئلة كل غابة، واختيارها حسب نقاط ضعف الطفل، وحساب الإتقان وفتح المناطق والغابات |
| `js/store.js` | حفظ ملفات الأطفال على الجهاز |
| `js/world.js` و`css/world.css` | عالم فلفولة: مظهر نهاري وفيلة صغيرة وأسماء لطيفة. لكل بطل عالمه (`p.look`) والافتراضي عالم فلفولة، ويبقى عالم المستكشفين اختياراً |
| `js/app.js` | الشاشات وطريقة اللعب |
| `sw.js` | حفظ ملفات اللعبة للعمل بدون إنترنت |

> عند تعديل أي ملف، غيّر رقم `CACHE` في `sw.js` حتى يصل التحديث للتابلت.
